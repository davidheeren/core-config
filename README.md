# core-config

Minimal config for Windows and Linux.

## Installation
You must run the script in the install directory!

### Windows
```powershell
git clone https://github.com/davidheeren/core-config.git
cd core-config\install
.\win-install.ps1
```

### Linux
```powershell
git clone https://github.com/davidheeren/core-config.git
cd core-config\install
.\linux-install.sh
```

## Includes

- lf, nvim, powershell, autohotkey, tmux, bash
